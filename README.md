# cyclistic-bike-share-analysis
SQL- and Tableau-based analysis of 6.17M Cyclistic bike-share rides, comparing casual riders and annual members to identify behavioral patterns and inform membership conversion strategies.


# Cyclistic Bike-Share Analysis

Google Data Analytics Professional Certificate Capstone

## Business problem
How do annual members and casual riders use Cyclistic bikes differently,
and how could those insights support conversion of casual riders to
annual memberships?

## Dataset
12 months of Divvy trip data
October 2025 – September 2026
6.17 million rides

## Tools
- MySQL / SQL
- MySQL Workbench
- Tableau Public
- Git / GitHub

## Workflow
Ask → Prepare → Process → Analyze → Share → Act

## Data processing
- combined 12 monthly datasets
- identified cross-month duplicates
- validated categorical fields
- investigated missing station data
- flagged invalid and >24 h ride durations
- created analytical variables

## Key findings
1. Casual riding is substantially more seasonal.
2. Casual usage increases on weekends; member usage decreases.
3. Casual rides are longer: 17.6 vs 11.9 minutes.
4. Members show morning/evening commute-like peaks.
5. Lakefront/tourist stations skew casual while downtown stations skew member.
